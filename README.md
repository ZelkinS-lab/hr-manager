# HR Manager (Система управления персоналом)

Мой первый учебный проект на Python с использованием ООП.

## Функционал:
- Добавление сотрудников
- Поиск самого высокооплачиваемого сотрудника
- Сохранение и загрузка данных в файл `employee.txt`

## Технологии:
- Python 3
- `@dataclass`, `@classmethod`, `@staticmethod`

## Дополнение:
Это является учебным проектом для ознакомления с системой Git и GitHub и последующей работой с ними!
